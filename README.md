# FF13 買い物分岐

FF13 Any% RTA 用の、ギル計画ツールです。9章の買い物と、11章マハーバラ坑道のチャート判定ができます。

**公開ページ**: https://ossy3126.github.io/ff13-shop-branch/

## できること

### 9章
- 必須購入 (クランク軸×32 + 極太の骨×37 または呪われた牙×39) と、セット (シャーマンサイン + ポーション×31) に、ギルが足りるか判定します。
- 1回目の買い物で足りない場合は、2回目の買い物の判定と、魔神のタリスマン売却 (+6,000G) による補填を計算します。足りないときは、必ず2回目の買い物をする前提です。
- フェニックスの尾の売却数は、所持数まで自由に決められます (最低2個は残すのが目安で、下回ると警告します。カラヴィンカ戦とバハムート戦で1個ずつ使うためで、特にカラヴィンカ戦では1個使う可能性が高いです)。
- スピカの回収・売却 (+7,250G) とシリコンオイルの回収 (+1,320G) を、チェックで収入に含められます。スピカは、チェックを入れているときだけ判定します。
- シリコンオイルの回収が必要か、フェニックスの尾を売るべきか (最低2個は残す) を判定します。
- 1回目で足りないときは、「A. 2回目の買い物 (魔神のタリスマンのみ)」と「B. フェニックスの尾を売って1回目で完了」を並べて表示し、11章への持ち越し額を比べられます。「この案にする」で切り替えます。Bが選べない (売れる数を全て売っても②に届かない) ときは表示しません。
- シリコンオイルの欄に、いまのフェニックスの尾の個数で、オイルを回収すれば1回目で終わるか (売却数をどれだけ減らせるか) を表示します。オイルを回収しても1回目で終わらないときは表示しません。
- 所持ギル (7章の買い物終了時は最低5,000G)、クレジットチップ、プレミアムチップの数を入れるだけで使えます。個数には、倒せる敵の数に応じた上限があります。

### 11章
- 9章の余りギルを自動で引き継ぎます (手入力も可能)。9章で足りなかった場合も、不足分をマイナスのまま引き継ぎます。
- 9章で魔神のタリスマンを売った場合は、11章の売却リストから除外します。
- 売却品とブリッジのドロップから、到達できる最高のルート (ルート1〜8) を判定します。
- 各パターンの行には、必要な超伝導体と、素材の内訳 (牙・骨・尾・ゼリー) を表示します。
- ブリッジ1・2のドロップ確率と、各チャートに届く確率を表示します (ドロップ個数の0個の確率も出ます)。
- 9章タブの確率表にも、7章ホープ邸・9章パラメキアの戦闘ごとの敵の編成を書いています。

### 共通
- 画面下の固定バーに、合計ギルと判定 (1回目で完了、2回目の買い物が必要、チャート到達など) を、色付きで常に表示します。
- PCでは、左に入力、右に結果の2列表示です。スマホでは縦並びになります。

## 使い方

ブラウザで公開ページを開くだけです。入力内容はブラウザに自動保存されます。「全部リセット」は、ドロップ入力の見出しの右にあり、2回押すと確定します (開いているタブは変わりません)。

## 補足

- ドロップ確率の根拠は、バトルアルティマニアです。
- 表示フォントは「UD デジタル 教科書体 NK」を指定しています (入っていない環境では代替フォントになります)。
- 単一の `index.html` だけで動きます。サーバーや外部ライブラリは使っていません。
